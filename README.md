# Барбершоп «Бритва и стиль»

Учебный проект по вёрстке: одностраничный сайт барбершопа, сделанный
на чистом **HTML + CSS** с минимальной интерактивностью на ванильном **JavaScript**
(мобильное меню и подсветка активного пункта в навигации).

## Структура сайта (карта сайта из задания)

1. **Главная** — герой-блок с ключевым посылом и статистикой.
2. **Наши барбершопы** (адрес, метро, график работы):
   - 2.1 Филиал на Тверской
   - 2.2 Филиал на Кутузовской
   - 2.3 Филиал в ЦАО
3. **Услуги и цены**:
   - 3.1 Мужская стрижка
   - 3.2 Бритьё опасной бритвой
   - 3.3 Камуфляж седины
   - 3.4 Укладка и стайлинг
   - 3.5 Комплекс «Борода + стрижка»
4. **Барберы** — фото‑карточки команды с указанием стажа и специализации.
5. **Портфолио работ** — четыре сравнения «До / После».
6. **Акции и клубные карты** — две акции и две клубные карты (Silver / Gold).
7. **Отзывы клиентов** — три карточки с оценками и подписями.
8. **Контакты** — телефон, соцсети (Telegram, WhatsApp, VK, Instagram),
   адрес, e‑mail и форма онлайн‑записи.

## Стек

- HTML5, семантическая разметка
- CSS3: CSS Grid, Flexbox, кастомные свойства (`--переменные`),
  адаптивность через `@media`-запросы (1100 / 960 / 720 / 480 px),
  `clamp()` для типографики, плавный скролл (`scroll-behavior`),
  SVG-иконки прямо в разметке
- Шрифты: Inter, Playfair Display, Bebas Neue (Google Fonts)
- Vanilla JS — мобильное меню и `IntersectionObserver`
  для подсветки активного пункта меню

## Дизайн

Тёмная палитра классического джентльменского клуба:
графитовый фон, кремовая бумага, тёплое золото в акцентах.
Гармонично сочетаются:

- засечечный шрифт Playfair Display — для заголовков
- широкий гротеск Bebas Neue — для надписей-«ярлыков»
- читаемый Inter — для основного текста

## Запуск

Никакой сборки не требуется. Достаточно открыть файл `index.html`
в любом современном браузере либо запустить локальный сервер:

```bash
python3 -m http.server 8080
# затем перейти на http://localhost:8080
```
